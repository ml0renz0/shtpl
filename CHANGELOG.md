# Changelog

- Bash compiler with arbitrary nested conditions and loops.
- Static validation, source-aware diagnostics, and private temporary workspace.

- Release workflow with archive and SHA-256 checksum.
- F07 release-candidate packaging verification, reproducibility and extraction smoke tests.
- Trunk-based automatic Semantic Versioning, version bump, tag and release publishing.
